Secuencia Completa de Cálculo y Sustitución Paso a Paso (Zona 1)

1. Capacidad Térmica Superficial (H2)

A = pi * (Diametro / 2000)^2

H2 = (Masa_kg * Cp) / (A * 1000)

Sustitución: (0.1029 kg * 385 J/kg·°C) / (0.00196 m² * 1000) = 20.18 kJ/m²·°C

2. Calor Acumulado (Q Sup / Inf)

Q_sup = (T_sup_z - T_sup_ini) * H2

Q_inf = (T_inf_z - T_inf_ini) * H2

Sustitución Z1: (31.95 - 25.49) * 20.184 = 130.39 kJ/m² (Sup)

3. Flux Térmico por Zona (Horno 1)

Flux_sup = (Q_sup / t_dwell) * 1000

Flux_inf = (Q_inf / t_dwell) * 1000

Sustitución Z1: (130.39 / (170/7)) * 1000 = 5369.04 W/m²

4. Coeficientes U (Sup / Inf)

U_sup = Flux_sup / (T_aire - T_avg_sup)

U_inf = Flux_inf / (T_banda - T_avg_inf)

Sustitución Z1: 5369.04 / (166.37 - 28.72) = 39.01 W/m²·°C

5. Temperatura Efectiva (Balance Coeficientes)

T_efec = [Flux_tot + U_sup*T_sup + U_inf*T_inf] / (U_sup+U_inf)

Sustitución Z1: [16198.54 + 39.01*31.95 + 77.93*49.79] / (39.01+77.93) = 174.31 °C

6. Offset del Horno 1

Offset_H1 = T_Real_HMI - T_efectiva

Sustitución Z1: 275 - 174.31 = 100.69 °C
